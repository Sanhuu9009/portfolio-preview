# 个人作品集网站

纯静态网站，可以直接部署在 GitHub Pages 上，带一个网页版后台 `/admin/`，用来管理作品、获奖、实践经历和个人介绍。不需要服务器，也不需要安装任何东西。

网站是深色的「放映厅」风格（右上角可切换浅色），主要交互有：

- 背景是一层缓慢流动的青金色光雾（WebGL），会被光标推开。
- 首屏的中文名由粒子拼成，光标划过时会散开再聚拢；下面的英文名是描边大字，光标靠近的字母会亮起。第一次打开时有一段 3-2-1 胶片倒计时片头。
- 「关于我」是便当格布局；精选作品会随滚动横向移动，封面像幕布一样揭开。
- 获奖麦穗会发光、逐片生长；有证书的奖项卡片可以翻面查看证书。
- 鼠标滚轮带惯性；按 `Ctrl/⌘ + K` 可以搜索作品和奖项；站内跳转时有幕布转场。

以上动效都可以在后台「网站设置 → 动效」里关闭。访客如果开启了系统的「减少动态效果」，会自动看到静态版本。

现在打开看到的是示例内容（「林知夏」），部署后在后台换成你自己的即可。

## 一、部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `portfolio`。公开或私有都可以，但私有仓库开启 Pages 需要付费账户。
2. 把这个文件夹里的全部文件推送到仓库的 `main` 分支：

   ```bash
   cd portfolio
   git init
   git add .
   git commit -m "init portfolio"
   git branch -M main
   git remote add origin https://github.com/你的用户名/portfolio.git
   git push -u origin main
   ```

3. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`，文件夹选 `/ (root)`，然后保存。
4. 等 1～2 分钟，访问 `https://你的用户名.github.io/portfolio/`。

> 如果把仓库命名为 `你的用户名.github.io`，网址就是 `https://你的用户名.github.io/`，不带后缀。

## 二、使用后台

### 1. 创建访问令牌（只需要做一次）

1. 打开 <https://github.com/settings/personal-access-tokens/new>。
2. **Token name** 随便填，例如 `portfolio-cms`。**Expiration** 选一个较长的期限，到期后重新生成即可。
3. **Repository access** 选 **Only select repositories**，只勾选你的作品集仓库。
4. **Permissions → Repository permissions → Contents** 设为 **Read and write**，其他保持默认。
5. 点 **Generate token**，复制以 `github_pat_` 开头的字符串。这串字符只显示一次，丢了重新生成即可。

这个 Token 只能改这一个仓库，即使泄露，影响范围也仅限于此。

### 2. 登录后台

打开 `https://你的用户名.github.io/portfolio/admin/`。用户名和仓库名会自动填好，粘贴 Token 后点「连接 GitHub」。

勾选「记住 Token」后，这台电脑以后打开会自动连接。在公用电脑上不要勾选，用完后到「连接与数据」点「退出并清除 Token」。

### 3. 编辑与发布

- 左侧依次是作品、荣誉奖项、实践经历、个人介绍、网站设置、连接与数据。
- 所有修改先保存在浏览器里。即使不小心关掉页面，下次打开也会询问是否恢复。
- 点顶部的「预览」，可以在新标签页看到包含未发布修改的网站，只有你自己能看到。
- 点「发布到网站」（快捷键 Ctrl/⌘ + S）提交到 GitHub，大约 1 分钟后网站更新。
- 上传图片时会自动压缩。也可以把图片直接拖到上传框里，或者截图后粘贴。

## 三、作品形式

| 形式 | 适合 | 内容 |
| --- | --- | --- |
| 视频 | 短片、纪录片、Vlog | B 站视频 + 作品说明 + 图片组 |
| 图文 | 公众号推文、摄影、海报、设计 | 正文（可插图）+ 图片组 |
| 文本 | 散文、诗歌、文案、剧本 | 正文，用适合阅读的版式显示，会统计字数 |

文本作品可以不放封面，卡片会自动摘录开头的文字当封面。其他作品的封面还会用作详情页顶部的背景氛围光。

### B 站视频

在作品的「B 站视频」框里粘贴以下任意一种即可：

- 视频页链接：`https://www.bilibili.com/video/BV1xxxxxxxxx/`
- BV 号：`BV1xxxxxxxxx`
- 嵌入代码：视频下方「分享」→「嵌入代码」复制的整段 `<iframe …>`

多 P 视频可以在旁边选择第几 P。手机 App 分享出来的 `b23.tv` 短链接无法识别，需要先在浏览器里打开，再复制地址栏里的完整链接。

正文中也可以插入额外的视频：点编辑器工具栏的「B站视频」即可。

> B 站对未登录观众的外链播放器有清晰度限制，这一点无法在网站这边绕过。

## 四、获奖与麦穗

在作品的「获奖」区域添加奖项，每个奖项可以填写：

- **获奖等级**：显示在麦穗中间的大字，例如「一等奖」「金奖」「最佳剪辑」。
- **奖项或赛事名称**：显示在等级下方。
- **麦穗颜色**：金、银、铜，或主题色（适合优秀奖、入围、荣誉称号）。
- **级别**、**获奖时间**、**颁发单位**。
- **获奖证书**：图片或 PDF。

每个奖项有两个独立开关：

- **展示获奖标签和麦穗**：打开后，作品卡片上出现金色「获奖」标签，卡片下方和详情页的「领奖台」显示两侧带发光麦穗的获奖名称，荣誉墙也会汇总这一项。
- **在作品页展示获奖证书**：打开后，作品详情页底部展示证书，点击可放大。

奖学金、优秀学生干部这类不属于某件作品的荣誉，请在「荣誉奖项」里单独添加。荣誉墙的排序方式，以及是否汇总作品获奖，可以在「网站设置」里调整。

## 五、本地预览（可选）

```bash
cd portfolio
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。直接双击 `index.html` 打不开内容，因为浏览器禁止本地页面读取数据文件。

在本地打开 `http://localhost:8000/admin/`，可以选择「本地文件夹」（需要 Chrome 或 Edge），直接修改电脑上的文件，改完后自己用 Git 推送。

## 六、常见问题

**发布后网站没变化？**
GitHub Pages 需要 1～2 分钟部署。可以在仓库的 **Actions** 页查看进度，完成后强制刷新页面（Ctrl/⌘ + Shift + R）。

**提示「线上文件已被其他地方修改」？**
说明你在别的电脑或直接在 GitHub 上改过内容。先在「连接与数据」里导出 JSON 备份，再点「重新载入线上内容」，然后重新修改。

**提示 Token 无效？**
Token 可能已过期，或者没有授权这个仓库。按第二部分重新生成即可。

**怎么删掉示例内容？**
在后台「连接与数据」点「清空示例内容」，然后修改个人介绍。示例图片在 `uploads/demo/`，确认不再使用后可以删除这个文件夹。

**想让 AI 帮我改网站？**
把仓库交给 Claude Code、Codex、Cursor 等工具即可，它们会先读 `AGENTS.md`，里面写清楚了结构和规范。改完内容后可以运行 `node tools/check.mjs` 做检查。
